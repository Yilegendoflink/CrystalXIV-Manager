# FF职业固定队经理2026

完全免费、非营利的同人单机模拟经营游戏，Crystal 开发版 v0.7。你负责八席固定队的招募、预约、机制分工和开荒指挥。

**建议从[游戏总案](策划案/01-游戏总案.md)开始。** 想推演一次团灭如何影响下一把，可以直接读[可复算的战报例子](策划案/11-机制判定与熟练度.md#可复算的战报例子)。

打开[网页版试玩](index.html)，选择炎帝陵进入 Crystal。桌面上的 **基本玩法.txt** 会带你从 **NGE** 招募、**QO** 排首发到 **Cook** 开怪。**Doc** 随初见点亮机制，累积探明度可解锁分工、主考属性和具体数值，也可在其特质图鉴里查询队员特质的效果。

[打开 Crystal 可点击界面稿](界面设计稿/index.html)可体验模拟样例。开发版与三段旧试玩分别保存进度，存档菜单可打开旧版记录。
