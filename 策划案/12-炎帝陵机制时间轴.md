# 12 炎帝陵时间轴与机制属性

炎帝陵采用用户重排的 P1、P2、P3 顺序，保留截图里的大部分技能效果，新增从场边发动的「深红旋风」。本章定义机制顺序、目标状态和判定口径。施放间隔、楔的生命值和伤害数值留作平衡参数。

## P1–P3 施放顺序

| 阶段 | 按顺序执行 | 结束条件 |
| --- | --- | --- |
| P1 | 火神爆裂 → 灼热咆哮／热风 → 烈焰焚烧 → 深红旋风 → 火狱之楔（4 根）→ 地狱之火炎 | 常规团伤结算后，存活队伍进入 P2 |
| P2 | 灼热咆哮／热风 → 地火喷发 → 光辉炎柱 → 火狱之锁 → 烈焰焚烧 → 火神爆裂 → 深红旋风 → 火狱之楔（8 根）→ 地狱之火炎 | 常规团伤结算后，存活队伍进入 P3 |
| P3 | 地火喷发 → 灼热咆哮／热风 → 火狱之锁 → 光辉炎柱 → 烈焰焚烧 → 火神爆裂 → 地狱之火炎（狂暴） | 首领生命归零即首通。狂暴结算时首领仍存活则团灭 |

烈焰焚烧在 P1、P2、P3 分别按 1、2、3 段设计。段数跟随阶段。灼热咆哮与热风是一个持续机制，先点名治疗，再产生周期伤害。火狱之炎由击破楔触发，记在楔机制内。持续效果可以跨到后续动作窗口，先后顺序表示触发顺序。任一阶段首领生命归零即结束战斗并结算首通。

## 首领目标状态与伤害归属

| 窗口 | 首领能否选中 | 普通攻击 | 队伍要做什么 |
| --- | --- | --- | --- |
| P1–P3 的可选中窗口 | 可选中 | 持续对当前一仇造成魔法伤害。成功换坦后，后续普攻打新一仇 | 坦克排减伤，治疗跟随一仇切换，输出维持首领伤害 |
| 深红旋风 | 不可选中 | 暂停普攻，冲锋由技能事件独立造成伤害 | 八席分散，各自观察场边冲锋方向、避开路线。首领归位后恢复可选中 |
| 火狱之楔，4 根与 8 根 | 不可选中 | 暂停普攻，击破楔产生火狱之炎 | 输出转打楔，坦疗处理引爆伤害。常规地狱之火炎落地结算后恢复可选中 |
| 地狱之火炎（狂暴） | 终局判定 | 战斗结束 | 结算首领剩余生命与总输出差，不进行生存掷骰 |

普攻与机制伤害可叠加，同一承伤窗口汇总结算。不可选中期间按技能或楔的规则推进，恢复可选中时重新开始普攻节奏。首领可选中时的伤害才扣首领生命，楔的伤害独立统计。冲锋和楔阶段的首领输出空窗由流程造成，战报把这段时间与可攻击时因走位、掉人造成的输出损失分开记录。

深红旋风在前两阶段各出现一次。每名队员按应变 70%、执行 30% 和自己的机制熟练度独立判定躲避。若个体躲避率为 `p₁…p₈`，八人都躲过的概率是 `p₁ × … × p₈`。有人中招时记录命中席位与存活时间，再按伤害和坦疗支援判定能否继续。复盘应精确到命中者及其躲避窗口。

两轮楔用同一个机制熟练度，分别配置 4 个和 8 个独立目标。每击破一根，就触发一次火狱之炎并结算对应的团队伤害与短暂易伤。楔窗口结束时锁定残留数量，常规地狱之火炎按这个数量提升团伤。队伍承受后仍可推进，残留本身不会额外触发一次失败掷骰。8 根版的调度空间来自任务分派、转火与错峰击破。

## 每个机制考察什么

主考和次考使用现有角色能力。**执行**看能否按预期时间完成走位、朝向或技能，**应变**看临时点名、连续变化和补救，**协作**看交接、报点、组间分配，**手法**看受干扰时还能完成多少有效操作。生存、机制、进攻是独立熟练度，分别作用在承伤、动作成功和输出损失。下表是策划上的权重建议。

| 机制名 | 主考 / 次考 | 重点席位 | 为什么这样配 | 分开结算什么 |
| --- | --- | --- | --- | --- |
| 攻击 | 执行 70% / 应变 30% | 当前一仇、负责外保与恢复的治疗 | 坦克按节奏覆盖魔法承伤，治疗应对血线偏差。稳定承伤主要靠预先排好的资源 | 按承伤窗口累计**生存**压力，一次普攻不单独发熟练度 |
| 火神爆裂 | 应变 70% / 执行 30% | 当时靠近首领的人，近战尤其敏感 | 无地面预显示的近身击退，第一步是读到动作并立即退出，第二步是走对方向 | **机制**决定是否吃击退，**生存**决定能否救回。近战提前退场的损失由**进攻**减轻 |
| 灼热咆哮 | 协作 70% / 执行 30% | 被点治疗、另一名治疗、需要挪位的搭档 | 从双治疗中随机点一人。被点者要让出团位，另一治疗同步接管团血和减伤。能否及时交接比单人反应更关键 | **机制**判断隔离和交接，**生存**判断分离后能否维持治疗覆盖 |
| 热风 | 执行 65% / 应变 35% | 被点治疗与经过其附近的玩家 | 周期性危险要求稳定保持间距。有人偏离预定路线时再考应变 | 作为灼热咆哮的子事件，记录每次损伤、击退和存活时间，同一次持续效果结算一次成长 |
| 火狱之楔 | 手法 65% / 协作 35% | D1–D4，报集火优先级的人 | 有限窗口里输出要够，同时得按分工避免漏打、重叠转火和把爆发打到错误目标 | 分配和转火用**机制**，是否按时打够用实际有效伤害，**进攻**决定移动时掉多少伤害 |
| 火狱之炎 | 协作 65% / 应变 35% | 叫停输出的人、双治疗、补团减的副坦 | 打掉目标会紧接全队伤害，节奏重叠时需要串行安排，并给治疗留恢复窗口 | **机制**判断能否把引爆错开，**生存**判断能否顶住现有易伤及爆发 |
| 烈焰焚烧 | 执行 75% / 应变 25% | 双坦为主，治疗跟进 | 朝向、换坦和减伤要提前安排。连续段数变长时，应变用于补救时序或覆盖缺口 | **机制**处理方向和交接，**生存**处理连击和叠层。连续命中属于同一组考核 |
| 深红旋风 | 应变 70% / 执行 30% | 八席全员，各自判定 | 冲锋从场边发起，先判断路径，再离开冲锋线。站位分散可减少同一路径命中多人 | 个人**机制**决定躲避，命中后结算**生存**和倒地时间。此处不计首领走位输出损失 |
| 地火喷发 | 应变 70% / 执行 30% | 随机被点者以及所在分组 | 在当前一仇以外随机点一人，脚下圆形预警后喷发。关键是及时选落点，把预警带出队伍路线 | **机制**决定是否把火带给队友，**进攻**缓解边移动边输出的损失 |
| 地狱之火炎 | 协作 65% / 应变 35% | 双坦双治疗，负责汇报剩余目标的人 | 团伤前安排减伤和恢复。楔未清会提高生存负荷，战报应追溯到此前漏打的目标 | **生存**判定使用实际残留楔数。楔击破时的团伤另记为火狱之炎 |
| 火狱之锁 | 协作 75% / 应变 25% | 当前一仇、随机一名输出，治疗处理额外承伤 | 双方拉远会加重持续掉血并压低伤害，移动时还要顾及坦克朝向。连线一方倒地，连接转移并重新计时 | **机制**判两人能否配合，**生存**处理持续掉血，**进攻**反映被迫改变输出窗口的代价。转移仍记在同一次连线下 |
| 光辉炎柱 | 执行 70% / 应变 30% | 八席全员 | 同时出现多处范围时，需要持续观察安全路线。重复走位考执行，临时绕路考应变 | **机制**处理走位，**进攻**处理输出空窗。失误幅度用来确定受伤或减员 |
| 地狱之火炎（狂暴） | 全程有效输出 | 全队 | 收尾技能按首领剩余生命直接判断结果 | 汇总此前可选中窗口的输出、掉人、走位停手和资源消耗，定位差值来源 |

### 和三项熟练度对应的复盘口径

- 动作失败对应机制熟练度，动作通过但撑不住对应生存熟练度，转火完成但伤害不足对应手法、实际输出窗口和进攻熟练度。前置目标漏打造成后续承伤增加时，战报指回漏打的原因。详见[机制判定与熟练度](11-机制判定与熟练度.md)。
- 持续效果中的多次伤害记在同一次机制下。玩家在该次机制实际存活越久，按资质、难度计算的成长越高。三次咆哮分别结算并共享咆哮熟练度，两轮楔也分别结算并共享楔的熟练度。
- 两个机制重叠时，战报各自记录失误、倒地和学习，实际伤害只扣一次被占用的时间。硬狂暴的输出差从先前掉人和停手的原因追查。
