# 08 技术与画面

[网页试玩](../index.html)是静态发布入口。v0.7 从启动器进入 Crystal 桌面，Doc、Cook、QO 和 NGE 共用队伍状态。Cook 通过独立的只读视图复用 WebGL2、Worker 与 Canvas 2D，显示战斗与队员血量。以下保留前期三段原型的画面规格，新版演出见[攻略指挥与压力演出](18-攻略指挥与压力演出.md)。

## 各层职责

| 层 | 技术与责任 |
| --- | --- |
| 经营和单次战斗模拟 | 负责存档、随机、时钟、事件及规则。对展示层提供阵容快照与有序结果流，正式结果以战报为准 |
| 场景生成 | 将内嵌脚本包装为 Blob URL 并启动 Web Worker。固定种子构造观测站几何和两个线上页面的像素底图，可重复生成 |
| 世界画面 | 使用原生 WebGL2 绘制水面、远山、平台、像素角色、机制预警与线上界面底图。静态几何上传一次，角色、预警与粒子随演出阶段更新 |
| HUD 和线上操作 | Canvas 2D 绘制首领生命、尝试次数、阵容生命、阶段说明、加载进度与语音波形。群消息输入、频道、名单、公告和排班管理采用可键盘操作的原生浏览器控件 |
| 音效 | Web Audio 的振荡器配合增益包络合成短提示。默认静音，点击音效开关后启动 `AudioContext`，切回静音时暂停音频上下文 |

炎帝陵每把先由模拟层写入成员快照、阶段判定、输出以及结果，WebGL2 与 Canvas 2D 按该战报回放，完整回放约 11 秒。尚无可回放战报时可查看前期观测站固定脚本，一轮 24 秒。绘制帧率、音量和页面切换不参与模拟结算。 [Khronos WebGL 2 规范](https://registry.khronos.org/webgl/specs/latest/2.0/) · [MDN Web Audio 自动播放说明](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

## 画布和抖动

- 世界与 HUD 使用两张同尺寸 `640×340` 画布，画面内像素坐标固定。页面按宽高比缩放，两张画布的位置和采样一致。世界 WebGL2 上下文禁用 `antialias`，同时关闭 WebGL 自带 `DITHER`。画布用 `image-rendering: pixelated` 最近邻放大，Canvas 图像平滑关闭。HUD 文字由本地字体在内部尺寸栅格化。
- 场景材质从有限的色板取色。夜空用深靛和灰紫，雾用灰紫和暗粉，水用深蓝和灰蓝。灯塔警示采用暖橘，角色以蓝、绿、橘区分坦克、治疗和输出，并显示席位文本。
- 片元着色器按内部像素 `gl_FragCoord` 查 `4×4` Bayer 矩阵。每个像素只从两个相邻的色板颜色里选一个，距离和高度控制选中比例。天空、地平线上的雾、水面反光都用该规则表现色阶。图案固定在内部像素网格，水面按低频离散步推进。
- 线上页延续角色色、有限色板与像素底图。语音页使用冷青卡片区分频道与发言，队伍群聊以暖色标出公告和经理发言。原生表单文字随页面尺寸排版，窄屏使用单列布局。

## 三个画面所承载的内容

| 画面 | 可看见的动作与信息 | 后续玩法的入口 |
| --- | --- | --- |
| 炎帝陵 | 红鳞巨蜥守在陵门前，八名像素小人按吐息、地火和石阵喷发变换阵型。红橙地面预警先于火焰出现。团灭、狂暴与首通都从结算数据读取 | 战前由经理排班和选择战术，战后从具体阶段决定复盘、休息或下一把 |
| 语音频道 | 可切换开荒、双治疗复盘和候补频道。成员卡显示当前频道、发言、未上线以及经理可见的压力 | 准备确认或分组练习前观察状态，随后可从经理看板进入复盘和私下谈话 |
| 队伍群聊 | 通过群公告、消息和成员名单演示周六 H2 请假。可发送本次演示内的消息，并安排或撤销雀斑补位 | 从排班卡处理请假、替补和改期，从名单进入成员管理。排班更新同步到群公告、名单与语音页摘要 |

八席小人在同一套像素体型下用盾、杖、刃、远程武器和色标体现职责。场次操作由经理页面执行，场内单元播放状态和结果。原型的发言状态与波形为模拟表现，群聊和替补操作在存档槽中自动保留。托管与恢复流程见[静态发布与存档](09-静态发布与存档.md)。

## 加载、离线和资源规则

Worker 依次报告初始化、观测站、炎帝陵、语音频道底图和群聊底图的生成进度。每份几何输出 `Float32Array`，通过 transferable 交由主线程上传到 GPU。加载进度达到 100% 后才开始演出。完成或出错后终止 Worker 并释放 Blob URL。WebGL2 初始化失败显示重试说明。 [MDN 内嵌 Worker 与数据传输](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers)

HTML、脚本、着色器、几何数据生成器和音效参数均封装在同一文件中。默认从系统选择微软雅黑、苹方或系统无衬线字体。仅在主动选择在线字体后请求 Google Fonts 的 Noto Sans SC 样式与字体，离线时通过字体栈继续显示。关闭在线字体后移除样式。场景生成和首帧无需等待字体网络请求。

## 验收

1. 断网时双击 HTML，加载条显示生成进度，三个场景均可切换，默认产生 0 个 HTTP 请求。
2. 炎帝陵能辨认 MT、ST、H1、H2、D1–D4。结算后回放应显示同一把的实际阵容、失败阶段或首通，场内鼠标与键盘动作不会改变演出。
3. 把战斗页面放到两倍大小，水、雾、夜空和预警范围可看清像素边界和 Bayer 网点。切换语音与群聊时世界画布尺寸仍为 `640×340`。
4. 点击音效开关能启动和暂停 `AudioContext`。主动开启在线字体后，即使断网，三个场景和本地文字仍能正常显示。
5. 在群聊发送一条消息并安排雀斑补位，群公告与名单显示 `8/8`。语音页能看到排班更新，雀斑的实时频道仍为候补待命。撤销补位后恢复 `7/8` 并留下操作消息。
