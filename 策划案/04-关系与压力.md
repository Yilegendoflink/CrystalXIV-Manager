# 04 关系与压力

## 双向好感度

队员对其他每位队员都有一条独立的好感度记录。`R(A→B)` 为 A 对 B 的好感，范围 `0–100`。大多数陌生人的两个方向分别从 `50` 开始，认识过的队员可以保留既有好感或冲突。首发、替补共用同一张关系表。临时换下或离队后再次加入，继续使用人物原有关系。`T(A)` 是 A 对经理的信任，范围 `0–100`，默认 `60`，独立于队友好感。

| 单向好感度 | 含义 |
| --- | --- |
| `80–100` | 亲近。对方也达标时才检查 CP |
| `60–79` | 友好 |
| `40–59` | 一般 |
| `20–39` | 紧张 |
| `0–19` | 对立。两者的配对关系标记为仇人 |

### 好感从哪里变

以下幅度为可调初值。每项事件以队员 ID、变化方向、前后值和触发战报入档。回放或重载沿用已经结算的事件。

| 事件 | 改变谁对谁的好感 |
| --- | --- |
| 有人在战斗中吃到意外伤害 | H1、H2 各自对该队员 `−5`。治疗本人吃伤时由另一名治疗结算自己的好感。同一次机制的连续伤害记为一次失误 |
| 某人成功救场 | 全队其他成员对救场者 `+6`。向队伍报告这次有效救场，对每名队员只记一次 |
| 新机制里首次交接顺利 | 两名搭档互相 `+2` |
| 重复迟报或在语音里指责 | 受影响成员对对应对象 `−3` 或 `−5`，方向由实际对话确定 |
| 随机互动 | 合拍带练可让两人互相 `+4`。发生摩擦时由受影响者对另一人 `−6`。档期、招募历史和已有关系可作为触发条件 |
| QO 双人调解 | 经理分别听取意见并约定一个可兑现动作。双方完成后可各 `+8` |

## CP 与仇人

每次事件完成后，按两人的最新值重新识别关系。一对异性成员互相好感均 `≥80` 时成为 CP。任意一方对另一方的好感 `<20` 时，这一对成为仇人。好感仍按原有方向保存。例如 `A→B=18，B→A=56` 会标记两人为仇人，B 对 A 的好感仍为 56。数值离开对应区间后结束该配对状态。好感达到 `20` 可解除仇人，恰好 `80` 达到 CP 的好感条件。

在实际共同出战的阵容里，每累计 30 游戏分钟结算持续压力。未共同出战的配对保留其状态，等两人同场后计时。日常看群聊、查看回放和等待经理开怪不消耗这段时间。

| 本段共同出战状态 | 压力变化 |
| --- | --- |
| 一对或多对 CP 同场 | 属于任一参战 CP 的成员各 `−2`，其他参战成员各 `+2` |
| 仇人同场 | 有参战仇人的成员各额外 `+6`，即使只有一个方向低于 20 |
| 两类关系同时涉及同一人 | 将该成员的两类压力加减相加，再走正常压力结算 |

同类持续压力按成员在每个结算点记一次。新产生的关系从后续持续压力结算开始生效。跨把时保存已累计的共同出战分钟。例：MT 与 H1 是同场 CP，H1 又与 D1 有敌对关系。若三人持续同场打两小时，单算关系影响，MT 压力 `−8`，H1 `+16`，D1 `+32`，无配对的其他人 `+8`。

### 关系事件与经理操作

| 关系 | 可触发事件 | 经理的应对 |
| --- | --- | --- |
| CP | 互相提醒机制、希望同一场出战、其他成员认为轮换不公平 | 安排共同担责、明确轮换理由，或按交接要求把任务拆开。队员感受通过具体事件改变 |
| 仇人 | 拒绝直接交接、争执打断报点、在群里互相指责 | 单独对谈、双人调解、改用第三人转述，或更换同场名单 |

关系成立或解除在 QO 私人队伍管理中可查。出勤或交接等行为触发的事件直接生成，其他互动按窗口从事件池抽取，同一次争执只写一条。40 项具体剧情、经理选项和数值见[CP 与仇人事件库](16-CP与仇人事件库.md)。持续压力照常可能触发固定 `50/50` 的压力检定。关系会影响触顶速度，概率按[攻关出勤、精力与压力](15-攻关出勤精力与压力.md)计算。

## 队内影响力

每周一更新 `I = clamp(30 + 3×连续在队周数 + 0.3×协作 + 0.2×(其他留队成员对其平均好感−50), 0, 100)`。排名前二且 `I≥55` 标记为领袖。双向好感均 `≥70` 的连接构成小群体，用于关系筛选。团队凝聚力用当前八席的有向好感均值表示，战斗按具体搭档的关系计入修正。

## 攻关中的精力与压力

攻关统一使用 `0–100` 的精力和压力。精力每日恢复为 100，压力随首次推进、重复团灭、队员对谈及关系事件改变。压力低于 30 时全项实战属性乘 `0.8`。触顶以固定 50% 判精神崩溃，否则触发坚定信念。临时状态持续 48 个游戏小时。具体事件数值、属性倍率与状态结算见[攻关出勤、精力与压力](15-攻关出勤精力与压力.md)。

### 压力与性格特质候选

每次坚定信念抽一项正面压力特质，精神崩溃抽一项负面性格特质。已抽取特质和两天的临时实战倍率分开显示。同名特质在同一成员身上只生效一次。现行的 20 项正面池、20 项负面池和战术利用条件详见[队员特质池](17-队员特质池.md)。

## 不满、续约和退队

周一计算留队意向 `L = clamp(50 + 0.5×(T−50) + 0.15×(对活跃队友的好感均值−50) + 目标进度 + 出场偏差 − 高压负荷, 0, 100)`。周目标兑现 `+10`、经队员确认延期 `0`、未协商落空 `−10`。出场达到承诺 `+5`、不足 `−10`，无首发承诺则 `0`。本周有过超时累计满 60 分钟或周末 `P≥85` 扣 `10`，两项并存扣 `20`。

`L<40` 一周后私下提出具体诉求，连续两周则进入去留会谈；`L<25` 一周直接进入去留会谈。会谈中可兑现补救或重谈条款。固定合约遇到持续不满可以提前退出，排班至少留下 48 游戏小时交接窗口。已提前告知无法出勤的现实变动单独进入日历处理。`L≥55` 且近两周信任回升时可主动续约。人物可能因现实事件拒绝下赛季续约，已知时在赛程末提前展示。
