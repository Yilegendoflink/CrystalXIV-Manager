# 18 攻略指挥与压力演出

## 经理的一个决策

如果把报距离和照顾连线伤害交给不同的人，就能避免同窗兼任。经理可以在 Doc 对照两个职责的要求和当前队员发挥，再决定由哪一席负责。开怪时锁定本把的指挥表，战报列出实际负责人和执行结果。

## Doc 队伍攻略

Doc 左侧是 P1、P2、P3 时间轴，中间以俯视动画示意预警、伤害范围、走位和处理顺序，右侧可在八席之间切换，查看队员的基础属性与当前发挥。分工绑定席位，替补接任首发时沿用该席位的职责。个人点名由副本结算，经理可以安排报点与处理职责。

新挑战的时间轴从全灰开始。每个节点独立记录探明度，包括不同阶段重复出现的同名机制。初次进入只点亮该节点并显示 `0%`。再次进入该节点后，探明度增量为 `基础增量 × 队伍学习倍率 × 队伍平均存活比例`，保留两位小数，最多累积到 `100%`。瞬时狂暴按到达结算点计。探明度和队员个人的三项机制熟练度分别保存。

基础增量随着已有探明度降低。`0%`、`30%`、`60%`、`100%` 分别对应 `16`、`5.30`、`3.65`、`2.65` 个百分点，相邻档位间线性变化。按全队八席的基础属性计算学习评分 `平均(资质 × 0.7 + 应变 × 0.3)`，用 `1 + (评分 − 64) / 125` 得到学习倍率，并限制在 `0.75–1.25`。满存活且学习评分为 64 的队伍，计入初见约在第 4、11、23 次到达同一节点时触及 30%、60%、100%。频繁早灭会延后这些里程碑。

| 探明度 | Doc 解锁内容 |
| --- | --- |
| 初见 | 点亮名称、处理简介和机制演示 |
| 30% | 可从合适席位中指定每项职责的处理者。此前每把从合适席位随机选人 |
| 60% | 显示各席位的主考属性和所选职责的考察属性 |
| 90% | 显示考察属性的具体数值，并与当前发挥比较 |
| 100% | 结算中的该节点属性要求乘 `0.8`。Doc 显示降低后的数值 |

开荒时 Cook 逐项播报初见与探明进展。分工和要求变化从下一把生效。旧存档通过历史最远进度恢复已见节点。已有自定义分工的已见节点从 `30%` 接续，其余已见节点从 `0%` 接续。

同一位队员连续主责时产生指挥负荷。能力、压力和熟练度影响实际执行。普通失误扣动作稳定、有效输出或承伤余量；阶段检查决定能否继续。冲锋时观察场边与分散，楔阶段转火，最后的狂暴检查读取全程有效输出。回放读取已结算记录，重看不消耗精力或再次抽样。

## 压力检定演出

每个触顶事件先确定成员、结果、压力重置值与新特质。画面收暗，放大该成员的原创像素头像，短促强震后显示「某某的信念正在经受考验……」。约一秒后揭示结果。坚定信念以白金字和放射光辉展开；精神崩溃以红黑字、短震和裂纹呈现。结果下方显示特质名、临时状态与重置压力。

多人触顶按队伍顺序排队，每次只展示一人。空格、回车或点击先揭晓，再继续。减少动态效果的系统偏好使用静态头像与颜色切换。所有按钮都有按下、弹起、选中与键盘焦点反馈。界面统一采用 Crystal 的晶石纹、压边面板和有限色板。

## 首批开发范围

Crystal 桌面上的 Doc 可编辑 22 个节点中的主责与协助工作，包括烈焰焚烧的换坦交接、楔阶段的分组集火、停手节奏和引爆后抬血。Cook 集中展示语音、WebGL2 游戏画面、八席血量、在场成员压力与精力以及事件窗口。战斗间隙可安排 10 分钟短休。

炎帝陵完整打一把消耗 20 个游戏分钟，含 2 分钟准备和 18 分钟机制时间。提前团灭或击杀按打到的时点结算，向上取整至分钟。灭团后可用 5 分钟复盘一次。在场队员对最后导致灭团的机制熟练度暂加 8、压力加 3。每累计两小时，在当前动作结束后决定提前收队、按预约继续或收队、延后两小时。延后须八席均可出勤且收队时间不超过次日 02:00。

战斗按同一把的分工快照、成员能力、有效精力、压力、探明度和个人熟练度结算。动作率限制在 12%–98%。本版同窗兼任每多一项减 8 个百分点，相邻机制连续主责减 6 个百分点。战报可展开查看指令、实际执行者及动作／生存抽样。跨机制的救场和意外受伤接入好感度事件，战斗结果更新压力。WebGL2 回放读取这些已结算节点，复看不会重掷。

当前接入六项压力特质作为第一批，完整特质库与 40 件关系剧情按各自策划继续开发。历史三段试玩及其 IndexedDB 槽位可由存档菜单继续，Crystal 战役单独记录攻略修订、队伍、社交信息、随机状态和进度。

发布入口为项目根目录 `index.html`，Crystal 的界面、样式与脚本随同 `界面设计稿/` 目录整体发布。Cook 通过同站点的只读观战页复用 WebGL2 世界、内嵌 Worker 和 Canvas 2D HUD。观战以压缩节奏逐项播放战斗事件，存档采用游戏内耗时。存档菜单支持三个 Crystal 槽位、JSON 备份和恢复上一份。新挑战从空队开始，通过 NGE 招齐八席，在 Cook 开荒后逐步解锁 Doc 分工。
