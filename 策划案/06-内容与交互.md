# 06 内容与交互

## 首季「潮汐观测站」

观测站的四级安全锁发生故障，队伍进入各层修复。候选人昵称、职业风格和副本机制均为原创。每层有一个能在战报里定位的主要难点。以下数值是首轮平衡基线，生命阈值以完成全部阶段的累计有效贡献为单位。

| 层与首领 | 阶段时长（分钟） | 关键职责 | 目标难度与卡点 | 生命阈值 |
| --- | --- | --- | --- | --- |
| 一层「值更者」 | 接管 2 / 断流 3 / 红线 4 | MT/ST 依序交接；H2 预防接 H1 恢复；D2/D3 处理转火 | 难度 2～7。教学先做坦克交接，随后辨别谁让恢复窗口失效 | 91 |
| 二层「归港钟」 | 回声 2 / 潮汛 3 / 夜航 3 / 钟鸣 3 | 八席分组站位；D3 读远点；D1/D2 错峰转火；H1 复起 | 难度 4～9。允许两层不同优先序，错位导致掉人或连带错位 | 95 |
| 三层「沉积者」 | 闸门 3 / 汇压 3 / 漂移 3 / 放流 3 | 双坦同步引导；双方治疗轮流负责；八席在不同侧交接 | 难度 6～11。连续伤害考验减伤分配与备用指挥 | 98 |
| 四层「零点灯塔」 | 校时 2 / 失步 3 / 合束 3 / 回摆 3 / 夜尽 3 | 前序战术汇总；双位指挥；分组后汇合处理转火 | 难度 7～13。可把稳健缺失的伤害通过装备、爆发和减少死亡追回 | 101 |
| 终局「误差归零」 | 六段，合计 17 | 同场执行多套节奏，中途交接指挥和救场资源 | 难度 9～15。要求四层首通且第 7 周已到；只给纪念奖励 | 103 |

### 原型一层的完整脚本骨架

| 阶段 | 机制序列 | 失败结果 | 救场与可练内容 |
| --- | --- | --- | --- |
| 接管 | ① MT 接班，难度 2；② ST 换坦，难度 3。两人使用 `0.7执行+0.3协作`，取对方为搭档，均受宽容站位影响 | MT 失败则 ST 的常规动作被阻断；ST 失败则首领面向偏离。两种均视为致命 | 可由另一坦应变救场（难度 7）。成功保留该段伤害损失。两人训练版本 |
| 断流 | ① H2 交保护，难度 7；② H1 恢复，难度 3。各用 `0.7执行+0.3协作`，互为搭档。保护受站位影响 | H2 失败则 H1 常规恢复被阻断，直接团灭。H1 失败记本段一人掉人（H1），能继续进入下一段 | H2 致命失败没有救场窗口。H1 失败可由 H2 救场（难度 5）避免掉人。双治疗训练版本 |
| 红线 | D2、D3 各做一次转火，难度 5，`0.6手法+0.4执行`，互为搭档。两人通过后要求该段加权输出 `≥86` | 转火仅 1 人失败可救，2 人失败或低于转火阈值直接团灭。随后按总伤害判狂暴 | 经理指定 D1 或 D4 救场（难度 6），计唯一资源。联合训练版本 |

一层阶段输出倍率均为 `1.00`。该表的宽容站位作用仅限标注的动作，样例使用「宽容站位 + 单人报点 + 灵活减伤」。灵活减伤在断流无救场窗口时不能覆盖该禁用规则。

| 阶段 | 机制序列 | 失败结果与战术空间 |
| --- | --- | --- |
| 回声 | D3 负责远端灯号，难度 4，`0.7执行+0.3协作`。选择一名副报点成员，作为 D3 的搭档。此项受双人报点影响 | D3 失败时可由副报点救场，难度 6。未指定副手或救场失败时，D3 与 D4 均受当段 `0.90` 的个人贡献损失，继续推进 |
| 潮汛 | 全员两两配对进分摊点，默认 MT/H1、ST/H2、D1/D3、D2/D4，可改配对。每人难度 7，`0.7执行+0.3协作`，受站位方案影响 | 1 人错位造成该人掉人。2 人错在不同组时两人掉人。2 人错在同组或至少 3 人错时团灭，无临场救场。默认组练按指定一组独立练习 |
| 夜航 | D1 与 D2 依序转火，难度 8，`0.6手法+0.4执行`，两人互为搭档。成功后本段加权结果必须 `≥88` | 单人失败可由指定 D3 或 D4 救场，难度 7。两人失败或阶段伤害不足时团灭。经理可为该段单独设置爆发时点，所有输出当段乘 `1.02`、钟鸣段乘 `0.98` |
| 钟鸣 | H2 预防，难度 8，`0.7执行+0.3协作`，受固定减伤方案影响。H1 恢复，难度 7，`0.6应变+0.4手法`，双方互为搭档 | H2 失败时 H1 原恢复被阻断，但灵活减伤可用 H1 触发难度 9 的救场。H1 独立失败会让 H1、H2 双双掉人并进入狂暴结算 |

二层阶段输出倍率均设为 `1.00`，打完一把需要 13 分钟。两处以上的可救窗口共享同一资源，玩家可指定将它留给特定阶段。日志显示资源是被使用、被保留，还是压根没有对应窗口。

## 事件剧本模板

CP 与仇人的 20 件触发事件、20 件随机事件见[CP 与仇人事件库](16-CP与仇人事件库.md)。

每个事件记录触发、涉事成员、经理能知道的证据、可选处置及到期行为。除压力过载与新段停顿外，一周最多主动弹出 3 个经理待办，其余进入周报。事件选项的数值结果只向玩家展示已知影响或方向。

| 事件 | 触发与证据 | 可选行动与兑现 |
| --- | --- | --- |
| 临时轮班 | 当周缺勤事件命中，显示变动时段和预计返场日 | 从候补锁位、改开场或取消。确认的承诺变化沿用重排和合同规则 |
| 「我到底是不是替补」 | 可训练的替补连续两周正式出场未达承诺，且没有自行缺席 | 用一次谈话设补救，在两场内兑现一次完整出场；兑现应用承诺奖励，过期应用失信 |
| 「先听谁的」 | 同一机制双指挥依赖冲突，重复失败两次 | 指定主副和话术，或调解。下次战报显示新的依赖和关系变化 |
| 「今晚又是复刷」 | 一名高挑战偏好的成员达到怠慢触发条件 | 约定新职责、安排带领下一组或让该成员主动休息。赛事有表现证据才结算怠慢干预 |
| 「这次轮到谁」 | 有可升级装备，经理拟分配给与公示方案不同的人 | 可保留原方案或解释并取得受影响人同意。未经协商覆盖时生成承诺违约 |
| 「换人还是换打法」 | 两场都在同一交接卡住，且双方关系至少有一向紧张 | 指定双人专项、调解或拆分责任。下一场把此前与当前分工并列在复盘中 |

| 存档 | 三个本地存档槽、当前槽与保存时间 | 继续某个赛季、导入或导出 JSON、恢复上一份。升级前备份可单独导出 |

群聊和语音频道是游戏内的模拟界面，参考 QQ 群的公告、消息与群成员分区，以及 Discord 的频道和活跃发言提示。队员受谁邀请、同意了哪次场次以及实际参加了哪晚，分别留痕。群里公布请假、换人及明确承诺，压力数值和私下谈话对经理可见。经理自由输入的演示消息只进入消息列表。正式版由排班、谈话或公告动作明确写入对应规则字段。

标色同时配文字、图标和数值。关系可用线图或表格，时间重叠可用表格呈现。首夜教学分三次出现：招募按档期筛选、复盘查首发责任、压力预警决定下一把。任何时候可打开术语和规则。比赛临时暂停后可存档，继续游玩回到这把结束后的状态。快速推进保留重要提醒，允许关闭已读的通用教学。

## 数据与存档行为

稳定唯一标识覆盖候选、合约、席位、日历、阶段、打法版本、成员关系、每周奖励、各次战斗快照和事件。存档记录赛季种子、当前周日与分钟、随机流位置、所有待办及目前规则版本。保存发生在完整事件结算后。自动快照在周二和周一保留最近三份，手动存档独立。

正式游戏的赛季快照属于各自的存档槽。后续版本以稳定标识与数据迁移保留阵容、成绩和待办，并逐版本校验。网页原型先以群聊、替补排班和槽位验证本地持久化。详细机制见[静态发布与存档](09-静态发布与存档.md)。

随机流拆分为候选池和现实事件、待定出勤、比赛检定、过载判定、特质及掉落。比赛检定按赛季、场次、战斗序号、阶段、机制和承担席位取样，跳过分支不会改变其他机制的判定。相同存档以相同操作推进应得到相同结果。只打开报告、拖动未提交草稿、重新载入均不消耗随机数。回合事件摘要保留全季，每把的详细日志至少保留本周、上周和每次首通的战报。
